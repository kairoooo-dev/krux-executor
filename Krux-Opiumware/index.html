Frequently Asked Questions

Is KRUX free?
Yes. KRUX is completely free and open source. No keys, no ads, no paywalls.
Does it work with the latest Roblox update?
KRUX v3 runs an external bytecode engine (Xeno) — nothing is injected into Roblox. Roblox updates can break memory offsets, so if no clients show up after Attach, grab the latest release from GitHub or Discord.
Is this undetected?
We do not guarantee bypass of any anti-cheat system. Use at your own discretion.
What scripts can I run?
Most Luau scripts work — roughly 75% UNC coverage including HttpSpy, readfile/writefile, getgenv, and Dex-style scripts. Script I/O routes through the built-in local bridge.
KRUX crashes when I click Attach. How do I fix it?
Make sure Xeno.dll and libwinpthread-1.dll sit next to KruxExecutor.exe — the installer does this automatically. Then open Roblox, join a game, and click Attach.
How do I attach to Roblox?
Open Roblox and join a game, then click "Attach" in KRUX. It detects clients externally — nothing is injected. The client count shows in the bottom bar, and Execute sends your script to every detected client.

Install KRUX

One command to install. One to uninstall.

Paste in PowerShell (Admin) and you're good to go.

iex (irm https://raw.githubusercontent.com/kairoooo-dev/krux-executor/master/install.ps1)

Uninstall: Run iex (irm https://raw.githubusercontent.com/kairoooo-dev/krux-executor/master/uninstall.ps1) in PowerShell.

Note: KRUX is Windows 10/11 only (x64). The installer pulls the latest v3.x release: KruxExecutor.exe plus the Xeno engine DLL. Make sure to join the Discord server for updates and support.
